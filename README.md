# Melodix — офлайн-студия для музыки на Android

Kotlin · Jetpack Compose · Media3/ExoPlayer · ONNX Runtime · JAudioTagger. Минимум Android 8.0 (API 26).
Интернет приложению не нужен вообще (в манифесте нет разрешения INTERNET).

## Возможности

**Плеер**
- Воспроизведение через ExoPlayer с аппаратными декодерами: MP3, AAC/M4A, FLAC, OGG/Vorbis, Opus, WAV, AMR, 3GP, MKA/WebM, ALAC (Android 9+), а также любые форматы, которые понимает прошивка.
- Фоновое воспроизведение, уведомление и управление с экрана блокировки и наушников (MediaSession).
- Очередь (перемешивание, повтор, перестановка), свайп по обложке для переключения треков, скорость и тональность, таймер сна с плавным затуханием.
- Медиатека: треки, альбомы, исполнители, папки, поиск, 5 видов сортировки, открытие любых файлов из проводника.

**Эквалайзер (собственный DSP, не системный)**
- 10 полос (31 Гц – 16 кГц), ±15 дБ, биквадратные фильтры по RBJ Cookbook в double-точности — одинаково точно на любом телефоне.
- Предусиление, полки баса/верхов, регулируемая добротность Q, ширина стерео, мягкий лимитер против клиппинга.
- Точная кривая АЧХ рассчитывается из тех же фильтров, что обрабатывают звук.
- 24 встроенных пресета + свои пресеты.

**Редактор**
- Форма волны с масштабом до ×20, ручки выделения, сдвиг границ по 0,1 с и 1 с.
- «Оставить выделенное» (обрезка) или «Вырезать выделенное»; стыки сглаживаются микрофейдами.
- Fade in/out, усиление, нормализация пика, реверс, предпрослушивание.
- Экспорт в WAV 16 бит (без потерь) или M4A/AAC 128–320 кбит/с в `Music/Melodix`.

**Разделение на вокал и инструментал**
- Нейросеть **UVR MDX-Net Inst HQ 3** (ONNX, ~64 МБ) работает прямо на телефоне. STFT/ISTFT реализованы в точности как в оригинальном Ultimate Vocal Remover (проверено против эталона).
- Три режима качества: «Быстро», «Баланс» (перекрытие блоков 50%), «Максимум» (перекрытие 75% + шумоподавление инверсией фазы).
- Можно импортировать другие MDX-Net модели `.onnx` (Kim_Vocal_2, Voc_FT, KARA и др.).
- Запасной быстрый DSP-метод (анализ стереобазы) — без нейросети.
- Работа в фоне с уведомлением о прогрессе.

**Теги**: название, исполнитель, альбом, исполнитель альбома, год, жанр, номер трека/диска, композитор, комментарий, текст песни, обложка. MP3 (ID3v2), FLAC, OGG, M4A, WMA, WAV, AIFF, DSF.

**Оформление**: 24 темы, своя картинка в качестве темы (цвета фото извлекаются и переносятся в градиенты, кнопки и акценты), размытие и затемнение фона, «живой» переливающийся градиент, фон плеера под цвет обложки, скруглённые элементы и плавные анимации (spring-физика, переходы между экранами).

## Сборка через GitHub (рекомендуется)

1. Создайте репозиторий на GitHub и загрузите в него содержимое архива (папка `.github` должна оказаться в корне).
2. Откройте вкладку **Actions** — сборка запустится сама (или нажмите *Run workflow*).
3. Через ~10–15 минут скачайте APK из раздела **Artifacts** сборки (`Melodix-apk`).
4. Если создать тег `v1.0.0`, APK автоматически прикрепится к GitHub Release.

Модель нейросети скачивается во время сборки и встраивается в APK, поэтому сам APK весит ~110 МБ.

## Сборка в Android Studio

Откройте папку проекта в Android Studio (Ladybug или новее), дождитесь синхронизации Gradle и нажмите Run.
Чтобы нейросеть была внутри APK, положите файл
[UVR-MDX-NET-Inst_HQ_3.onnx](https://github.com/TRvlvr/model_repo/releases/download/all_public_uvr_models/UVR-MDX-NET-Inst_HQ_3.onnx)
в `app/src/main/assets/models/`. Без него будет доступен DSP-метод и импорт модели из файла.

## Честно об ограничениях

- **Разделение без «остаточных шумов вообще» невозможно ни в одной программе**, включая студийные: это восстановление информации, которой в стерео-миксе в явном виде нет. MDX-Net HQ3 — одна из лучших открытых моделей, но в сложных миксах (реверберация, бэк-вокал, дисторшн) лёгкие артефакты возможны. Режим «Максимум» заметно их уменьшает ценой времени.
- Скорость нейросети зависит от процессора: на современных флагманах трек 4 мин обрабатывается за 2–4 мин в режиме «Баланс», на бюджетных телефонах — дольше.
- Набор форматов воспроизведения определяется декодерами устройства (APE, WMA, DSD на большинстве телефонов аппаратно не поддерживаются).
- Для сохранения тегов на Android 11+ разрешите «Доступ ко всем файлам» (Темы → внизу) или подтверждайте запрос системы при каждом сохранении.
